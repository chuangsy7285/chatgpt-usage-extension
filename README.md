# ChatGPT 用量小幫手 v0.5.2

## 更新／安裝
1. 解壓縮 ZIP。已安裝者以新版檔案覆蓋原資料夾。
2. 開啟 chrome://extensions，開啟「開發人員模式」。
3. 新安裝選「載入未封裝項目」，選取包含 manifest.json 的資料夾；已安裝者按外掛的「重新載入」。
4. 接受 Chrome 顯示的 chatgpt.com 網站權限，再重新整理 ChatGPT 分頁。
5. 點側欄「更新」或工具列外掛的「立即更新」確認結果。

## 背景更新
使用 Chrome 現有登入狀態，GET 請求 https://chatgpt.com/backend-api/wham/usage 。無須保留用量頁，也不會另開分頁。需 Chrome 120 以上。
每約 30 秒嘗試同步；瀏覽器休眠、省電或關閉可能延遲／暫停。失敗後等 5 分鐘再自動重試，手動更新可立即重試。
5 小時剩餘與每週剩餘皆為 100 − used_percent，重置時間使用 reset_at 秒數轉換。只保存兩項額度、重置時間、最後成功讀取時間與錯誤狀態；不保存回傳中的姓名、Email、帳號識別碼、點數資料。

## 驗證與限制
這是非官方、未公開保證穩定的網站介面。已根據使用者提供的回傳結構做解析與模擬請求測試，尚未在使用者登入環境驗證直接請求能否成功。
請求設定 credentials: include，讓瀏覽器處理現有 Cookie，不使用 cookies 權限、不讀取 Cookie 內容；401 時嘗試從同站 /api/auth/session 取得 accessToken，只在背景程式記憶體暫存最多約 5 分鐘，不寫入 storage、不傳回面板或其他網站，不向第三方傳輸。
登入狀態不代表此請求一定成功：若伺服器要求額外的授權標頭／驗證，可能回傳 401 或 403。此時會顯示錯誤、保留最後紀錄，不假裝更新成功，也不繞過網站驗證。可重新登入後手動重試；若仍失敗，需要改用頁面讀取或正式支援的存取方式。
側欄用量區塊採正常排版，保留帳號上方間距。百分比為最後成功讀取值；倒數到零不自動補滿。
若手動背景更新失敗且當前用量面板已開啟，可回退讀取可見文字。
本機清除：工具列面板按「清除本機紀錄」。完整移除：chrome://extensions 按「移除」。

## v0.5.2 登入驗證修正
使用 Cookie 直接查詢遇到 401 時，嘗試取得目前網站登入工作階段的 accessToken，並在同站用量請求附加 Bearer 標頭。此工作階段端點及其格式未由本次使用者資料確認，必須在實際瀏覽器測試。若端點不支援、沒有憑證或仍回傳驗證錯誤，顯示錯誤並保留舊紀錄。不繞過 403、安全挑戰或登入限制，不要求使用者手動複製憑證。

## v0.5.2 自動更新啟動
開啟 ChatGPT、重新切回 ChatGPT、開啟外掛面板時，會主動觸發同步；背景仍每約 30 秒更新。多個分頁同時觸發時共用同一次請求，近期成功同步不重複請求。保留手動更新按鈕作為立即重試用途，正常使用不必點擊。
登入驗證修正與自動更新共用同一套邏輯。網路／驗證錯誤仍顯示原因並延後 5 分鐘自動重試，不重複高頻嘗試登入。
